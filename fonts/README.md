These fonts are embedded into the card SVGs, because an SVG shown through `<img>` can't load fonts from anywhere else.

- `news-*.woff2`: [Newsreader](https://github.com/productiontype/Newsreader), Display and Text optical sizes
- `pixel-*.woff2`: [Pixelify Sans](https://github.com/eifetx/Pixelify-Sans)

Both are licensed under the SIL Open Font License 1.1 (see the `OFL-*.txt` files). The files here are cut down to basic Latin plus a few punctuation marks to keep the cards small. A character outside that set falls back to a system font.
