These fonts are embedded into the card SVGs, because an SVG shown through `<img>` can't load fonts from anywhere else.

- `tiny5-400.woff2`: [Tiny5](https://github.com/Gissio/font_tiny5), for running text and labels
- `pixel-700.woff2`: [Pixelify Sans](https://github.com/eifetx/Pixelify-Sans) Bold, for the big display lines only
- `jersey10-400.woff2`: [Jersey 10](https://github.com/scfried/soft-type-jersey), for numbers and dates

All three are licensed under the SIL Open Font License 1.1 (see the `OFL-*.txt` files). The files here are cut down to basic Latin plus a few punctuation marks to keep the cards small. A character outside that set falls back to a system font.
